# Movie Ticket Booking App

A modern movie ticket booking application built with React, TypeScript, and Material-UI, inspired by BookMyShow.

## Features

- 🎬 Browse movies with detailed information
- 🎟️ Book tickets with interactive seat selection
- 💳 Secure payment integration with Razorpay
- 📱 Responsive design for all devices
- 🔍 Search and filter movies
- 📍 Location-based theatre suggestions
- 🎨 Modern UI with smooth animations

## Tech Stack

- React 18
- TypeScript
- Material-UI
- React Router
- Razorpay Integration
- Local Storage for state management

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/movie-ticket-booking.git
cd movie-ticket-booking
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
